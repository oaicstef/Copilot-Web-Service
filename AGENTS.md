# AI Memory: copilot-web

## Project Overview
`copilot-web` is a mobile-friendly front-end for the GitHub Copilot CLI running on a Raspberry Pi, served via [ttyd](https://github.com/tsl0922/ttyd). 
It works by generating a patched `ttyd` HTML page that inlines custom CSS and JS to provide responsive layout, on-screen key controls, and font-size adjustments.

## Architecture & Infrastructure
- **Host**: The service runs on a Raspberry Pi 5 (`192.168.0.156:7681`).
- **Reverse Proxy**: Located on the same network, an N100 server runs Nginx Proxy Manager (NPM).
- **Domain**: `oaiccopilot.duckdns.org` points to the NPM server, which forwards traffic to the Pi. Proxy configurations (like SSL and headers) are handled externally on the N100.

## Core Technologies
- **Vanilla JavaScript & CSS**: No UI frameworks (React, Vue, etc.) or CSS frameworks (Tailwind) are used. 
- **Node.js Scripts**: Used for building the artifact (`web/build.mjs`) and testing.
- **WebSocket Interception**: `web/overlay.js` intercepts `window.WebSocket` to send custom input frames over the existing `ttyd` connection.
- **Testing**: `jsdom` is used for unit testing DOM interactions in Node.

## Project Structure
- `web/overlay.js`: The core logic for key bar, font controls, status, and WebSocket capture.
- `web/overlay.css`: Toolbar and status styles.
- `web/build.mjs`: Fetches `ttyd`'s page and inlines the overlay to produce `web/index.html`.
- `web/index.html`: The built artifact (git-ignored). Do not edit directly; modify `overlay.js`/`overlay.css` and run the build script.
- `tests/overlay.test.mjs`: Unit tests using JSDOM.
- `diagnose.sh`: Read-only end-to-end diagnostic tool for checking the proxy and `ttyd` status.
- `test-service.sh`: curl-based pass/fail checks of the same chain; credentials via `COPILOT_USER`/`COPILOT_PASS`.
- `install.sh`: Idempotent installer (runs with sudo) to set up the systemd service.
- `systemd/`: systemd unit file and environment launcher.

## Development Workflows
- **Build**: `npm run build` (regenerates `web/index.html`).
- **Test**: `npm test`
- **Lint**: `npm run lint`

## Important Rules
- Do NOT edit `web/index.html` manually. It is generated by `web/build.mjs`.
- Make sure to respect the vanilla JS/CSS architecture. Do not introduce dependencies unless strictly required and approved by the user.
- Security: Take care not to compromise the proxy header overwrite (`X-Copilot-Auth`) which protects the ttyd instance.
